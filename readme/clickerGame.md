# 🎮 لعبة تحدي النقر (Click Challenge)

## 📌 وصف المشروع

لعبة تعتمد على سرعة النقر والتركيز، حيث يجب على اللاعب الوصول إلى عدد معين من النقرات خلال وقت محدد في كل مستوى.

تتكون اللعبة من **10 مستويات**، وتزداد صعوبة اللعبة تدريجيًا من خلال زيادة عدد النقرات المطلوبة وتقليل الوقت المتاح.

## 🚀 مميزات المشروع

- نظام مستويات يتكون من 10 مستويات.
- مؤقت زمني مستقل لكل مستوى.
- زيادة عدد النقرات المطلوبة تدريجيًا.
- تقليل الوقت المتاح مع التقدم في المستويات.
- شريط تقدم يوضح نسبة الإنجاز.
- إمكانية إعادة اللعبة من البداية.
- إمكانية الخروج إلى الصفحة الرئيسية.
- التحقق من وجود عناصر HTML الأساسية قبل تشغيل اللعبة.

## 🛠️ التقنيات المستخدمة

- HTML5
- CSS3
- JavaScript (Vanilla JS)

## ⚙️ إعدادات اللعبة

| الثابت            | القيمة | الوصف                                   |
| ----------------- | -----: | --------------------------------------- |
| `MAX_LEVEL`       |     10 | الحد الأقصى للمستويات.                  |
| `START_SECONDS`   |     60 | الوقت الأساسي للمستوى الأول بالثواني.   |
| `TIME_DECREASE`   |     32 | مقدار الوقت الذي ينقص في كل مستوى.      |
| `BASE_CLICKS`     |    250 | عدد النقرات المطلوبة في المستوى الأول.  |
| `CLICKS_INCREASE` |      5 | مقدار زيادة النقرات المطلوبة لكل مستوى. |

> **ملاحظة:** التعليق الموجود بجانب `START_SECONDS` يذكر دقيقتين، لكن القيمة الفعلية هي 60 ثانية (دقيقة واحدة).

## 📖 شرح المتغيرات

| المتغير       | الوصف                                                                  |
| ------------- | ---------------------------------------------------------------------- |
| `clicks`      | عدد النقرات التي نفذها اللاعب في المستوى الحالي.                       |
| `level`       | رقم المستوى الحالي.                                                    |
| `secondsLeft` | الوقت المتبقي للمستوى الحالي.                                          |
| `started`     | يحدد ما إذا كان المؤقت قد بدأ أم لا.                                   |
| `interval`    | يخزن معرف المؤقت الناتج عن `setInterval`.                              |
| `finished`    | يحدد ما إذا كانت اللعبة قد انتهت.                                      |
| `waitingNext` | يحدد ما إذا كان اللاعب قد أكمل المستوى وينتظر الانتقال للمستوى التالي. |

## 🧩 شرح الدوال (Functions)

### 1. `target()`

تحسب عدد النقرات المطلوبة لإكمال المستوى الحالي.

**طريقة الحساب:**

```javascript
BASE_CLICKS + (level - 1) * CLICKS_INCREASE;
```

مثال:

- المستوى الأول: 250 نقرة.
- المستوى الثاني: 255 نقرة.
- المستوى الثالث: 260 نقرة.

### 2. `levelTime()`

تحسب الوقت المتاح لإكمال المستوى الحالي.

**طريقة الحساب:**

```javascript
START_SECONDS - (level - 1) * TIME_DECREASE;
```

مثال:

- المستوى الأول: 60 ثانية.
- المستوى الثاني: 28 ثانية.
- المستوى الثالث: -4 ثوانٍ.

> ⚠️ **ملاحظة برمجية مهمة:** قيمة `TIME_DECREASE = 32` تجعل الوقت سالبًا ابتداءً من المستوى الثالث، وبالتالي لا يمكن إكمال المستويات العشرة. يجب تعديل قيمة تقليل الوقت إذا كان الهدف إكمال جميع المستويات.

### 3. `formatTime(totalSeconds)`

تحول الوقت من عدد الثواني إلى صيغة دقائق وثوانٍ بالشكل التالي:

`MM:SS`

**المعاملات:**

- `totalSeconds`: عدد الثواني المراد تحويلها.

**آلية العمل:**

1. استخدام `Math.floor()` لحساب الدقائق.
2. استخدام باقي القسمة `%` لحساب الثواني.
3. استخدام `padStart()` لإضافة صفر إلى بداية الأرقام عند الحاجة.

**مثال:**

```javascript
formatTime(125); // 02:05
formatTime(60); // 01:00
```

### 4. `updateTimer()`

تحديث الوقت الظاهر على واجهة اللعبة.

تستدعي الدالة `formatTime()` لتحويل الثواني المتبقية إلى صيغة مقروءة، ثم تعرض النتيجة داخل عنصر HTML الذي يحمل المعرف `timer`.

### 5. `stopTimer()`

إيقاف المؤقت الزمني.

**آلية العمل:**

- تتحقق من وجود مؤقت فعال.
- تستخدم `clearInterval()` لإيقافه.
- تعيد قيمة `interval` إلى `null`.

تُستخدم عند انتهاء الوقت أو إكمال المستوى أو إعادة اللعبة.

### 6. `endGame(won)`

إنهاء اللعبة سواء بالفوز أو الخسارة.

**المعاملات:**

- `won`: قيمة منطقية (`Boolean`) تحدد نتيجة اللعبة.
  - `true`: فوز اللاعب.
  - `false`: خسارة اللاعب.

**المهام التي تنفذها:**

1. تعيين حالة اللعبة إلى منتهية.
2. إيقاف المؤقت.
3. تعطيل زر النقر.
4. تغيير شفافية الزر.
5. عرض رسالة مناسبة حسب نتيجة اللعبة.

### 7. `startTimer()`

تشغيل المؤقت عند أول نقرة من اللاعب في المستوى الحالي.

**آلية العمل:**

1. تتحقق من أن المؤقت لم يبدأ وأن اللعبة لم تنتهِ.
2. تغير قيمة `started` إلى `true`.
3. تستخدم `setInterval()` لتنفيذ عملية كل ثانية.
4. تنقص قيمة `secondsLeft` بمقدار ثانية.
5. تحدث الوقت المعروض على الشاشة.
6. تنهي اللعبة بالخسارة عندما يصل الوقت إلى الصفر.

### 8. `renderLevel()`

تجهيز واجهة المستوى الحالي وإعادة ضبط بياناته.

**المهام التي تنفذها:**

- إيقاف المؤقت السابق.
- تصفير عدد النقرات.
- تحديث رقم المستوى.
- حساب عدد النقرات المطلوبة.
- حساب الوقت المخصص للمستوى.
- تحديث المؤقت.
- إعادة ضبط شريط التقدم.
- تفعيل زر النقر.
- إعادة تعيين رسالة اللعبة.
- تصفير حالات بدء المؤقت والانتظار للمستوى التالي.

تُستدعى عند بدء اللعبة والانتقال بين المستويات وإعادة تشغيل اللعبة.

## 🖱️ شرح الأحداث (Events)

### 1. حدث النقر على زر اللعبة

```javascript
button.addEventListener("click", () => {});
```

يتعامل مع نقرات اللاعب، ويقوم بالمهام التالية:

1. يمنع تنفيذ العمليات إذا كانت اللعبة منتهية.
2. يتحقق مما إذا كان اللاعب ينتظر الانتقال للمستوى التالي.
3. يبدأ المؤقت عند أول نقرة.
4. يزيد عداد النقرات.
5. يحدث عدد النقرات الظاهر على الشاشة.
6. يحسب نسبة التقدم.
7. يحدث عرض شريط التقدم وقيمة `aria-valuenow`.
8. يتحقق من إكمال المستوى.
9. ينقل اللاعب إلى حالة الانتظار للمستوى التالي أو ينهي اللعبة بالفوز عند إكمال المستوى الأخير.

### 2. حدث إعادة تشغيل اللعبة

```javascript
restartBtn.addEventListener("click", () => {});
```

يعيد اللعبة بالكامل إلى حالتها الأولية:

- إيقاف المؤقت.
- تصفير عدد النقرات.
- العودة إلى المستوى الأول.
- إعادة الوقت الأساسي.
- إعادة ضبط جميع حالات اللعبة.
- استدعاء `renderLevel()` لتجهيز المستوى الأول.

### 3. حدث الخروج من اللعبة

```javascript
exitBtn.addEventListener("click", () => {});
```

يوقف المؤقت الحالي ثم ينقل اللاعب إلى الصفحة الرئيسية باستخدام:

```javascript
window.location.href = "index.html";
```

## 🏗️ عناصر HTML المطلوبة

يجب أن يحتوي ملف HTML على العناصر التالية حتى تعمل اللعبة بشكل صحيح:

| المعرف أو المحدد | الوظيفة                            |
| ---------------- | ---------------------------------- |
| `timer`          | عرض الوقت المتبقي.                 |
| `count`          | عرض عدد النقرات الحالية.           |
| `level`          | عرض رقم المستوى الحالي.            |
| `required`       | عرض عدد النقرات المطلوبة.          |
| `bar`            | شريط التقدم.                       |
| `.progress`      | الحاوية الخاصة بشريط التقدم.       |
| `message`        | عرض رسائل اللعبة.                  |
| `click-btn`      | زر النقر والانتقال للمستوى التالي. |
| `restart-btn`    | زر إعادة تشغيل اللعبة.             |
| `exit-btn`       | زر الخروج إلى الصفحة الرئيسية.     |

## 🔄 آلية عمل اللعبة

1. عند فتح الصفحة يتم التحقق من وجود عناصر HTML المطلوبة.
2. يتم تجهيز المستوى الأول.
3. يبدأ المؤقت عند أول نقرة.
4. يستمر اللاعب في النقر حتى يصل إلى العدد المطلوب.
5. عند إكمال المستوى يتوقف المؤقت.
6. يظهر زر الانتقال إلى المستوى التالي.
7. تتكرر العملية حتى إكمال المستوى العاشر.
8. عند إكمال جميع المستويات تظهر رسالة الفوز.
9. إذا انتهى الوقت قبل إكمال المستوى، تنتهي اللعبة بالخسارة.
